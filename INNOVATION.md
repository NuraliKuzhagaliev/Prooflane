# Product opportunities and implemented differentiation

The strongest demonstrated direction is a reproducible review, not another generic financial chat. The implementation now supports explicit source decisions, shared-variable alternatives, exact conditional ranges and cent-level priority boundaries. Their combination is specific to the review task; individual matching, duplicate checks, scenario planning and sandbox controls are established ideas.

| Capability | Concrete user purpose | Delivered evidence |
| --- | --- | --- |
| Two independent dated sources | Resolve which price applies before calculating | Explicit C2R choice and reasoned INV506 exclusion |
| Shared-contract changes | Avoid editing dependent invoices separately | C1 affects three rows;368 shared /568 joint alternatives |
| Exact ranges and next evidence | Identify which missing source can reduce declared uncertainty |148..1993 two-factor fixture, independent cents oracles |
| Priority boundary | Find the first cent changing the largest review item |82.59 strict /82.60 tie /82.61 new leader |
| Portable packet | Let a colleague reconstruct the review without trusting a screenshot | Source/receipt/change/boundary reconstruction, seven groups |
| CSV and readable brief | Give AP colleagues usable handoff formats | Reasons, source rows, warnings and excluded scope preserved |
| Duplicate financial-row warning | Expose a deterministic data-quality concern | No automatic fraud claim or silent exclusion |
| Recovery identity | Avoid blindly repeating an unknown charged request | Durable request ID, replay conflict, status-only recovery |

Initial ideas were prioritized by value, originality, feasibility, demonstrability, rule fit, risk and effort. Row-level verification, receipts and containment were core; controlled alternatives grew only after the base contract worked. Multi-model comparison, payment actions, a generic agent marketplace, speculative microVM claims, automatic contract truth and unrelated features were excluded.

Next useful experiments are a second-reviewer reconstruction study and an equal-task comparison with Excel, measuring correctness, preparation effort and time. These are proposals. No demand, willingness to pay, saved hours or recovered money has been measured. The model's value for a fixed arithmetic contract remains a question to evaluate rather than a claim to hide.

A stronger isolation broker or signed receipts would require their own threat model and actual runtime/key-management validation. Adding their names to a pitch without implementation would not improve evidence. [Methods](docs/INTELLIGENCE_METHODS.md), [current gates](docs/FINAL_SUBMISSION_20261109.md).
