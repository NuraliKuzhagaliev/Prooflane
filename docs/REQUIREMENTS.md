## Product acceptance

- Upload valid independent CSVs, resolve overlap/exclusion explicitly, then freeze a baseline. Malformed/oversized input is rejected; unverified scope is not called zero variance.
- Preserve original sources and the baseline. Shared-contract alternatives update every bound row; joint changes apply together to the original, with declared lineage and revision checks.
- Reject incomplete/mismatching model output and ambiguous duplicate-key packets. Never execute generated code when Docker is unavailable. Unknown cleanup blocks future execution.
- Show honest Reference, Sandbox recipe and Vultr agent provenance. Reference is trusted arithmetic, not independent code verification. Preserve failed attempts and safe diagnostics.
- Make source rows, code, actual runtime metadata and receipt available. Reconstruct packet arithmetic without executing packet code. Unsigned hashes do not establish identity or source truth.
- Respect session ownership, Origin controls, body/resource limits and quotas. Recover a pending operation by identity rather than silently retrying a charged POST.
- Provide keyboard paths, visible focus, reachable controls, responsive reading order and reduced-motion code paths. Observed responsive/keyboard checks pass; full screen-reader listening, physical touch and system-motion testing remain NOT_RUN.
