# Prooflane на Agent Rush · аудит 7 ноября 2026

Prooflane соответствует технической части **Blast Radius Zero, Pattern A**. Живой Vultr Inference сгенерировал Python, программа выполнилась в Docker, а результат прошёл независимую проверку. Для завершения заявки нужны публичный GitHub с проверенным доступом, финальное видео с моментом изоляции и подтверждение подачи в LabLab. Победу определяют жюри и качество других заявок. Ниже оценка готовности по наблюдаемым результатам.

Официальное закрытие подачи — **9 ноября 2026 в 04:00 по времени Казахстана**, 8 ноября в 23:00 UTC. Рабочий ориентир — подать **8 ноября до 22:00 по Казахстану**, чтобы осталось время на проверку ссылок и загрузку видео. Для публичного пути достаточно фиксированного Docker с действительными ограничениями и отдельно обозначенного сохранённого AI-прогона. Существующий `PROOFLANE_OPERATOR_TOKEN` следует хранить на сервере. Переход на другой runtime и расширение до OCR или платежей целесообразно обсуждать после подачи.
