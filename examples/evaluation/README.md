# Independent synthetic CSV examples

All data is fictional. Expectations in `cases.json` were calculated manually, not generated by production `summarize`. Reference and fixed-recipe actual Docker are evaluated separately. This is not a model-quality benchmark or proof of Vultr hosting.

| File | Billed / positive-variance calculation | Expected findings |
| --- | --- | --- |
| `no-variance.csv` | `2*10 + 3*7.50 = 42.50`; variance0.00 | None |
| `decimal-prices.csv` | `3*0.30 + 2*0.10 = 1.10`; `3*(0.30-0.10)=0.60` | Record2 |
| `duplicate-ids.csv` | `12 + 2*8 + 3 = 31.00`; `2 + 2*1 = 4.00` | Records2,3 share an invoice ID |
| `quoted-multiline.csv` | `2*12.34 + 3*2 = 30.68`; `2*2.34 + 3*1 = 7.68` | Records2,3 regardless of physical line breaks |
| `untrusted-text.csv` | `2*8.75 + 4 = 21.50`; `2*0.50 = 1.00` | Record2; Unicode, HTML-like text and note instructions remain data |
| `bom-whitespace.csv` | `2*2.50 + 4*0.75 = 8.00`; `2*0.50 + 4*0.25 = 2.00` | Records2,3; BOM/whitespace/blank physical line |
| `large-amount.csv` | `999999*99999999.99 = 99999899990000.01`; `999999*0.01 = 9999.99` | Record2; stress fixture, not realistic billing |
| `positive-only.csv` | `15 + 2*3 + 2 + 1 = 24.00`; `5 + 4 + 1 = 10.00` | Records2,3,4; negative differences are not subtracted |
| `invalid-negative-price.csv` | Negative price | HTTP422 |
| `invalid-fractional-quantity.csv` | Fractional quantity | HTTP422 |
| `invalid-extra-column.csv` | Unquoted extra comma/column | HTTP422 |
| `invalid-price-precision.csv` | More than two decimal places | HTTP422 |

A source record is a parsed CSV record with the header numbered1. Quoted embedded newlines and blank physical lines do not add record numbers.

Start the application and Docker as described in the root README, then run:

```powershell
.venv/Scripts/python.exe scripts/evaluate_csv.py --output artifacts/evaluation-local.json
```

Expected full result:24/24 passed, exit0. Checks include exact values and findings, actual returned receipts/input/mode/runtime, zero model calls, Docker cleanup and cross-session denial. Failure records FAIL and exits1. There is no hidden fallback to Reference.

Without Docker, `--mode reference` runs12 cases and does not verify isolation. For an authorized deployed app, specify its actual `--base-url https://YOUR_HOST` and separate output file. The full corpus creates16 successful records and never requests VSI or an operator token. The URL alone does not attest hosting provenance.

The notes-instruction fixture checks data handling in a bounded workflow; raw rows are not sent to a model here, so it is not an adversarial LLM benchmark. Current regression/runtime evidence is in [TESTING](../../TESTING.md).
