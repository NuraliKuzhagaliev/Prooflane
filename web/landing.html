Before you open a review

A few useful answers.

What can I try without an account?+

Open the workspace and choose “Open a reviewed example.” It uses fictional invoice and contract files and trusted Reference rules. There is no model call, sign-up or payment step. You can inspect sources, explore assumptions and export the case.

Does every review use AI?+

No. Reference mode uses fixed arithmetic. Sandbox mode runs a fixed Python recipe in Docker. Vultr agent mode requests generated Python from Vultr Serverless Inference and requires an operator token. The workspace labels the actual mode.

What files does Prooflane accept?+

Invoice and contract CSVs with the columns shown in the workspace’s field guide. Matching uses exact vendor and item keys plus inclusive contract dates. This prototype does not scan PDFs, connect to an ERP or make payments.

What does a positive difference mean?+

It means a billed unit price exceeds the supplied contract price for an included row. It is a signal for review, not proof of fraud, contractual liability or recovered savings.
